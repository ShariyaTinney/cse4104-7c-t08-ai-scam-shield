\## 📌 About the Project



Online and mobile-financial-service fraud is a growing problem in Bangladesh.

Fake bKash and Nagad messages, phishing links, fake job or prize offers and

impersonation calls trick thousands of people, especially students, elderly

users and small business owners. Most existing tools are English-centric,

only filter messages, and never teach users how to protect themselves.



\*\*AI Scam Shield\*\* is a web application that understands Bangla, English and

Banglish, explains \*why\* a message is risky, and trains users through

realistic scam simulations.



\---



\## 🧩 Core Modules



| Module | What it does |

|---|---|

| 🔍 \*\*Scam Checker\*\* | The user pastes a suspicious message, link or phone number. The system returns a risk level, the red flags found (false urgency, PIN/OTP requests, suspicious links) and advice on what to do next. |

| 🎭 \*\*AI Scam Trainer\*\* | An interactive simulator where the AI plays a scammer (fake bKash agent, prize message, fake job offer). The user practises resisting it, then gets feedback and a score. |



\---



\## ✨ Proposed Features



\- 🔐 User registration and login (JWT authentication)

\- 🔍 Scam Checker with risk score and plain-language explanation

\- 🎭 AI Scam Trainer with scenario-based role play and scoring

\- 📊 Dashboard with scan and training history

\- 🛠️ Admin panel to manage scenarios and review reported scams

\- 🌐 Bangla, English and Banglish support



\---



\## 🤖 Why AI?



\- \*\*Language understanding:\*\* scam messages change constantly and mix Bangla and

&#x20; English, so fixed keyword rules fail.

\- \*\*Adaptive training:\*\* AI generates varied, realistic role-play scenarios that a

&#x20; static quiz cannot.

\- \*\*Explainability:\*\* users learn from the explanation, not only the verdict.
